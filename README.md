Password Vault
자주 사용하는 웹사이트 계정 정보(아이디 및 비밀번호)를 터미널에서 간편하게 관리할 수 있는 초간단 파이썬 스크립트입니다.
로컬 환경에서 빠르고 가볍게 비밀번호를 기록하고 찾아볼 수 있습니다.

기능
- 저장된 계정 목록 조회
- 새로운 사이트 계정 정보 추가
- 불필요한 계정 정보 삭제
- JSON 파일을 통한 데이터 자동 저장

설치 및 실행 방법
1. 레포지토리 클론 git clone https://github.com/username/PasswordVault.git cd PasswordVault
2. 스크립트 실행 Bash셸 -> python vault.py
3. 입력값
- 메뉴 선택 (1: 목록 조회, 2: 계정 추가, 3: 계정 삭제, 4: 종료)
- 사이트 이름 및 계정 정보 입력

사용예시:
- --- [1] 목록 조회 [2] 계정 추가 [3] 계정 삭제 [4] 종료 ---
- 선택: 2
- 사이트/서비스 이름: github.com
- 아이디/비밀번호 정보: my_id / my_password

결과:
- --- [1] 목록 조회 [2] 계정 추가 [3] 계정 삭제 [4] 종료 ---
- 선택: 1
- - 사이트: github.com | 아이디/비번: my_id / my_password

요구사항
- Python 3.x
- 추가 라이브러리 없음 (표준 라이브러리 `json`, `os`만 사용)
